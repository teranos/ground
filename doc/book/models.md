## models-globalRules
A rule is a condition and the model it picks. Every rule is asked before the plain model, and the first that holds wins.

## models-globalDefault
Every ritual runs under this model unless its project or the ritual sets one.

## models-twoGlobalSrc
One models block at each level. Every pbt is folded into one parse, so a second block anywhere would replace the first without a word.
