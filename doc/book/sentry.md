## sentry-hostName
k's ground and the Mac's report into one project, and nothing they sent said which machine it came from. Every log and metric does now.

## sentry-globalOnly
What goes: the ritual's name as the monitor, the performance id as the check-in, and a status — in_progress at the start, ok or error at the end.

## sentry-emptySrc
A sentry block with no dsn says nothing and is not a report address.

## sentry-unknownFieldSrc
An unknown field inside the block is refused rather than ignored: a misspelled key would otherwise silently report nowhere.

## sentry-twoGlobalSrc
One sentry block at each level. Every pbt is folded into one parse, so a second block anywhere would replace the first without a word.

## sentry-commentedSrc
Not the output a rite printed, not the agent's words, and no absolute path: a worktree path names whose machine it is, and sentry is off that machine.

## sentry-performanceEnvelope
An ending says what became of the agent. One left running is the failure a person otherwise meets as a machine out of memory, so it is an error even when the ritual itself is done.

## sentry-stamped
An item is closed where it is built and stamped where it is left: the funnel reopens it for the one attribute the builder could not know, the session's model, and closes it again. Stamping an open item is str.

## hooktiming-sqlite3_open
One watcher claims; a second finds nothing left to claim. A duration each, and the phases that are not total or exit. A post that did not land hands the rows back; one that did keeps them.

## outbox-sqlite3_open
